# fillmark

Fill digests and mark fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/fillmark/

## Install / run

```bash
git clone https://github.com/theworker02/fillmark.git
cd fillmark
node src/cli.js
node --test
```
